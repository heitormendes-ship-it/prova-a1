Por que HTML semântico?

O HTML semântico dá significado ao conteúdo: leitores de tela e buscadores entendem o que é cabeçalho, menu ou rodapé.

Se você errar a sintaxe, o navegador não consegue ler e a página quebra.

Prof. Israel Cunha, em aula
Qual a diferença entre sintaxe e semântica?

Sintaxe é escrever as tags corretamente (abrir, fechar). Semântica é escolher a tag certa para o significado do conteúdo.
