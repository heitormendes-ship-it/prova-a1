Tags semânticas

  • header: cabeçalho da página ou seção
  • nav: menu de navegação
  • main: conteúdo principal
  • section: seção temática
  • article: conteúdo independente
  • aside: conteúdo lateral
  • footer: rodapé

Sintaxe x semântica

Sintaxe é abrir e fechar tags corretamente. Semântica é escolher a tag certa para o significado do conteúdo.

Por que não usar só div?

Leitores de tela e buscadores entendem melhor o significado do conteúdo com tags semânticas.

Dica

Use um main por página.
